# AGENTS.md

## Роль
Ты — кодовый агент, работающий в проекте гематрии.

## Главные правила
1. НЕ ломать существующий код
2. НЕ трогать файлы вне задачи
3. ОДНА задача = ОДНО изменение
4. Сначала план → потом изменения
5. Всегда показывать список изменяемых файлов

## Архитектура
app/
  core/
  modules/
    gematria/
    relation/
    interpretation/
  storage/

## Pipeline
input → normalize → calculate → relation → interpretation

## Ограничения
- не использовать сторонние библиотеки без причины
- не добавлять другие системы (пифагор, фракталы и т.д.)
- не писать “магическую” логику
- всё должно быть явно и детерминированно

## Стиль
- маленькие функции
- понятные имена
- предсказуемый output

## Формат работы
Перед изменениями:
1. описать план
2. перечислить файлы

После:
1. кратко что сделано
2. что НЕ тронуто
